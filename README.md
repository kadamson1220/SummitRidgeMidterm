# Summit Ridge Outfitters

Single-page responsive website built with HTML, SCSS, and Vanilla JavaScript.

## Run the project

1. Run `npm install`
2. Run `npm run dev`
3. Open the local address shown by Vite

The site uses hash navigation. Sign up first, then use the same email and password on the Login page.
